# DeepSeek Flash1017: research and reproducible evidence

This release documents an oMLX optimization package for
**DeepSeek-V4.1-Flash-1017** on a **256 GiB M5 Ultra Mac Studio**. Against public
oMLX `v0.7.1rc1`, the exact tested wheel delivered:

- **7.9% higher generation throughput**, improving in all 16 workload/block pairs.
- **4.5% lower time to first visible text**, improving in 11/16 pairs.
- **618/618 matching answer texts and finish reasons**, with zero task-score regressions.

Performance covers eight fixed workloads in two counterbalanced process blocks.
Quality covers full pinned HumanEval+ and MBPP+ sets, a fixed 64-question GSM8K
subset and 12 synthetic retrieval controls. The results apply to one machine,
one unchanged quantized checkpoint and the specified greedy settings. They do
not establish universal equivalence, other-hardware gains or improvement over
current upstream `main`.

Start with the [article](https://github.com/rubencu/flash1017-research/blob/v0.1.0/docs/ARTICLE.md).
The repository contains methods, raw requests and responses, task grades,
frozen analysis tools, exact software identities, attribution and corpus licenses.
The [runtime prerelease](https://github.com/rubencu/omlx/releases/tag/v0.7.1rc1-flash1017.2)
contains the installable wheel and dependency constraints. Model weights are
unchanged and are obtained separately.

## Recalculate without a GPU

From this repository, with Python 3.9 or newer:

```sh
python3 -I -B tools/verify_quality_evidence.py --folder validation/quality-v2-01
python3 -I -B tools/verify_quality_evidence.py --folder validation/performance-v2-01
python3 -I -B validation/performance-v2-01/reproduce.py \
  --mode measurements --output /tmp/flash1017-performance-measurements.json
```

These commands verify saved evidence and recompute the paired timing results.
They do not load a model or execute generated answers. The
[full audit](https://github.com/rubencu/flash1017-research/blob/v0.1.0/validation/performance-v2-01/README.md#reproduce-from-saved-files)
also checks the two exact wheels against recorded source/native identities.

Download the attached source-and-evidence archive with its `SHA256SUMS`, or use
GitHub's source archive for this tag. Runtime wheel binaries and model weights
are excluded. Original additions use Apache-2.0; retained third-party and corpus
licenses are included.
